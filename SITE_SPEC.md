# MINJU CHOI Portfolio — v1 Site Spec

## Positioning
**I BUILD WAYS TO CREATE.**

The portfolio should not feel like a decorated resume. It should read as three connected bodies of work:
1. **MONOV — Building AI content workflows**
2. **Commercial — Ideas that left the screen**
3. **Film & Stage — Stories made with people**

The through-line is: content production → technology → repeatable creative systems.

## Visual language
- Core palette: deep purple / black / warm white.
- Typography: oversized sans-serif, tight tracking, hard editorial hierarchy.
- No gradients, 3D decoration, mouse-follow cursors, fake grain, tiny serif captions, or “international studio” clichés.
- Film imagery keeps square corners and original cinematic framing.
- MONOV UI can use tighter digital layouts and subtle borders.

## Interaction principles
Only interactions that communicate structure or craft:
- Section reveal on scroll.
- Full-screen / near-full-screen project panels.
- MONOV video cards autoplay on hover and reset on mouse leave.
- Sticky MONOV studio chapter on desktop.
- Image scale is subtle on homepage project hover.
- No scroll hijacking.
